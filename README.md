# Interphone project

ESP32 door-entry prototype with QR visitor access, a resident web app, a Supabase backend, and hardware designs.

- [Software, firmware, and setup instructions](interphone/README.md)
- [Software plan](interphone/docs/PLAN.md)
- [Hardware brief](interphone/docs/PROJECT_CONTEXT.md)

The root folder contains the Fritzing drawings, exported wiring netlists, component list, and shopping list. Hardware operation has been verified; cloud-to-hardware integration and video/audio calling remain to be completed.

Local credentials, dependency folders, generated builds, and the discard folder are excluded from version control. Copy the supplied example configuration files when setting up a new machine.
